# MD Mazidul Hasan – Senior QA Automation Engineer Portfolio

Welcome to the personal portfolio website of **MD Mazidul Hasan**, a Senior QA Automation Engineer specializing in test automation, framework development, and continuous integration.

## 🚀 Overview

This repository hosts my professional portfolio, designed to showcase my expertise, experience, and projects in the field of Quality Assurance and Software Testing. The website features a modern, dark-themed design with interactive elements to provide an engaging user experience.

🔗 **Live Portfolio:** [https://MazidulHasan.github.io/](https://MazidulHasan.github.io/)

## ✨ Features

-   **Hero Section:** Dynamic introduction with social media links (LinkedIn, Medium, GitHub).
-   **About Me:** Comprehensive professional summary, journey, and career approach.
-   **Technical Skills:** Visual representation of proficiency in tools like Playwright, Cypress, Selenium, Rest Assured, and more.
-   **Testing Philosophy:** Detailed explanation of my testing focus areas (Functionality, Usability, Performance, Security, etc.).
-   **Featured Projects:** Interactive carousel showcasing key projects with descriptions and GitHub links.
    -   SauceDemo Automation
    -   Playwright Boilerplate
    -   DSA Learning Tracker
    -   Fullstack Docker App
-   **Learning Journey:** A timeline of my continuous learning path from manual testing to advanced AI-driven automation.
-   **Medium Blog:** Links to my latest articles and insights on software testing.
-   **Responsive Design:** Fully optimized for desktops, tablets, and mobile devices.

## 🛠️ Technology Stack

-   **HTML5:** Semantic structure and content.
-   **CSS3:** Custom styling, variables, animations, and responsive layout.
-   **JavaScript (Vanilla):** Interactive components, carousels, and dynamic content.
-   **FontAwesome:** Scalable vector icons.

## 🚀 Getting Started

To view this portfolio locally on your machine:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/MazidulHasan/MazidulHasan.github.io.git
    ```

2.  **Navigate to the project directory:**
    ```bash
    cd MazidulHasan.github.io
    ```

3.  **Open `index.html`:**
    Simply open the `index.html` file in your preferred web browser.
