About Me

Senior QA Automation Engineer with 6+ years of experience turning product risk into clear test strategy, reliable automation, and fast feedback for release teams. My strongest hands-on focus is Playwright with JavaScript, especially maintainable UI automation, authentication flows, fixtures, API checks, and CI-ready test frameworks.

What I Focus On

I build test systems that teams can actually maintain: Playwright JavaScript frameworks, Page Object Model patterns, storageState authentication, reusable fixtures, API-assisted setup, stable selectors, and readable reports. I still use Cypress, Selenium, Rest Assured, Postman, and performance tools when they fit the problem, but my portfolio now intentionally points visitors toward my strongest automation lane: modern Playwright-based quality engineering.

My Approach

I apply a shift-left and risk-based quality engineering mindset, starting with requirement analysis to align testing strategy with system architecture and business objectives. I embed automation into CI/CD pipelines using Jenkins, Docker, and Git to enable fast, reliable feedback across Agile releases.

My approach combines Playwright-first UI automation, API validation, performance testing with Gatling, and structured defect management in JIRA. I work closely with distributed, cross-functional teams to drive early defect detection, maximize test coverage, and support high-confidence production releases.
