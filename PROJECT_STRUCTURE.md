# Project Structure and Build Guide

This document describes the structure and the build process of the portfolio website.

## Overview

The portfolio is a static HTML/CSS/JS website. To keep the code maintainable, the main `index.html` file is generated automatically from smaller, manageable section files. The `index.html` file should **not** be edited directly, as any changes made to it will be overwritten during the next build.

## Directory Structure

```text
MazidulHasan.github.io/
├── css/                  # Contains all styling for the site (style.css)
├── js/                   # Contains all scripts for interactivity (script.js)
├── media/                # Images, documents, and media assets
├── sections/             # Modular HTML files for different parts of the UI
│   ├── 00_head.html      # Meta tags, title, link to stylesheets
│   ├── 01_navigation.html# Navbar component
│   ├── 02_hero.html      # Hero/Landing section
│   ├── 03_about.html     # About me section
│   ├── 04_skills.html    # Skills and tools list
│   ├── 05_test_approach.html # Approach to software testing
│   ├── 06_projects.html  # Featured projects carousel
│   ├── 07_learning.html  # Timeline/Learning journey
│   ├── 08_medium.html    # Medium blog articles
│   ├── 09_contact.html   # Contact information
│   └── 10_footer.html    # Footer component
├── build.py              # Python script that generates index.html
├── index.html            # The autogenerated entry point
└── README.md             # Project overview
```

## How to Make Changes

To edit content, update the corresponding HTML file inside the `sections/` directory.

### Example: Adding a New Project
1. Open `sections/06_projects.html`.
2. Add the content (e.g., a new carousel badge and a carousel item card) to the existing code.
3. Save the file.
4. Run the build script to regenerate `index.html`.

## Running the Build Process

To compile the sections into the final `index.html` file, run the `build.py` script. You must have Python installed.

```bash
python build.py
```

The script will read all `.html` files in the `sections/` directory in alphabetical order and concatenate them sequentially into the `index.html` file at the root.

**Output Example:**
```bash
Building index.html from sections...
  Added 00_head.html
  Added 01_navigation.html
  ...
Successfully built index.html!
```

**Note:** Always commit your changes to both the specific files in the `sections/` directory and the autogenerated `index.html` output to keep your remote repository up-to-date and seamlessly deployed via GitHub Pages.
